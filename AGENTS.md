# Working on Bot Skill Creator

Canonical root: this directory. Product name: Bot Skill Creator; slug: bot-skill-creator.
Two interfaces, one compiler: browser studio and CLI/NDJSON harness mode.
Run `python -m unittest discover -s tests -v` before a code change is called verified.
The optional Chromium script is `python scripts/browser_smoke.py`.

Do not silently rewrite preserved provenance documents or the inherited control kernel.
Do not import the separate BOT Skills collection into this repository or add invented
skills to it. The inventory example is a fictional fixture for THIS product only.

Never execute business APIs from the creator. An imported operation is a capability
contract, not installed access. Remote model keys may be sealed only in the user secrets
folder outside this repository. Never put them in project files, browser storage, exports, or logs.
Never expose controller Authority signing methods as tools to a model.
No secrets in fixtures. No untrusted HTML insertion; render model/imported content with textContent.
Do not claim universal compatibility, model superiority, production SaaS readiness,
live-provider testing, or exactly-once remote effects from static tests.

Keep startup dependency-free and readable in Bash and PowerShell. A complete skill
export must contain SKILL.md, readable docs, selected API contract, workflow, validation
helper and manifest. Validate every path and do not overwrite existing skill folders.
Keep human docs short at the front; place detailed proofs and limitations in docs/MATH.md.
