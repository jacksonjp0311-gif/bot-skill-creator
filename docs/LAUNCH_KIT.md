## Claims to avoid

No “works with every agent,” “guaranteed safe,” “self-improving intelligence,” or
“proven better” claims. Do not label the local studio as a live public platform.
Use current release test evidence and show one working export rather than inflated metrics.

## First contributor requests

A reproducible real-world read-only workflow, a narrowly scoped importer fixture,
an accessibility improvement, or a harness integration report that states exactly
which runtime/version was tested. Do not solicit secrets or proprietary API dumps.
